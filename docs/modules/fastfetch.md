# fastfetch

[fastfetch](https://github.com/fastfetch-cli/fastfetch) — neofetch
alternative written in C, much faster.

## Logo with image rendering (Kitty graphics protocol)

```sh
fastfetch --logo System/Images/1.jpg --logo-height 28 --logo-type kitty
```

Needs `imagemagick` for the kitty logo type. See
[Logo options](https://github.com/fastfetch-cli/fastfetch/wiki/Logo-options).

## Logo with ASCII

```sh
fastfetch --logo System/ASCII/fenrir.txt
```
